01

專案概述

深河出版為文化文學領域之出版公司，期望建置一個以「品牌識別」為核心的互動式網站。網站以流動的水為視覺意象，呼應「深河」品牌精神，並以柔軟、流動、與讀者親近的調性，串連品牌介紹、出版品、活動紀錄與專欄等內容。

本提案依雙方先前確認之「方案二（柔化精簡版）」方向擬定，於原訂預算範圍內，呈現與參考站 takamaru-fukuoka.com 一致的柔軟流動氛圍。

02

需求摘要

  • 品牌定位：文化文學出版，視覺以青花瓷色調（鈷藍 / 黑 / 白）為基調
  • 視覺調性：柔軟、流動、與讀者親近；入口及全站具水波 / 漣漪意象
  • 內容範圍：品牌介紹、出版品、活動紀錄、專欄、周邊、聯絡
  • 後台需求：可由貴司自行新增與維護文章、出版品與活動紀錄
  • 語系：中文 / 英文 / 日文，三語系架構
  • 預算：新台幣 30 萬以內
  • 上線時程：預計 2026 年底至 2027 年初
03

網站架構

全站共規劃 11 個頁面，涵蓋品牌、內容與聯絡三大區塊：

區塊頁面說明
品牌首頁水波主視覺入口，帶出品牌精神與最新動態
品牌關於深河品牌故事、出版理念、團隊介紹
內容出版品（列表 / 內頁）書系與書籍展示，提供外部購書連結
內容活動紀錄（列表 / 內頁）文字、照片與內嵌影片之活動記錄
內容專欄（列表 / 文章內頁）編輯手記與專欄文章，後台可定期新增
內容周邊（列表 / 內頁）周邊商品展示，採「聯繫專人洽詢」
聯絡聯絡我們聯絡表單與基本資訊
頁面架構與內容相對位置已透過線上概念示意與貴司確認。
04

視覺與互動方向

  • 色調：以深河品牌青花瓷色票（鈷藍 / 黑 / 白）為基調
  • 水波互動：柔光暈擴散漣漪，呈現柔軟流動的呼吸感（非線圈疊加形式）
  • 版面：無邊界 / 柔化邊框，段落之間連貫流動，消除區塊切割感
  • 導覽：全裝置收合式選單，並於展開選單提供站內搜尋
  • 頁尾：極簡呈現，品牌標準字（中英文）等距置中
視覺與互動方向已透過線上概念示意與貴司溝通確認：
開啟線上概念示意 →
細部之美術設計將於本案設計階段正式產出。
05

技術方案

  • 後台核心：以 WordPress 為內容管理系統，搭配客製化主題開發
  • 前端：客製化切版，以 Canvas 製作柔光水波互動與滾動動畫
  • 三語系：採多語系架構，中 / 英 / 日三語切換（譯稿由深河出版提供）
  • 響應式設計：桌機、平板、手機皆完整呈現（RWD）
  • 效能最佳化：圖片格式最佳化、延遲載入、行動裝置降階，確保載入速度
06

08

服務不包含項目

為使範圍明確，下列項目不包含於本提案（方案二）：

  • WebGL 立體流體波紋、游標文字互動、滾動水流轉場（屬方案一，如需請另行議定）
  • SEO 自然搜尋優化與付費廣告投放
  • 線上金流與電子商務購物功能
  • 英文、日文翻譯撰寫（譯稿由深河出版提供）
  • 網站內容文案之撰寫（文字內容由深河出版提供）
